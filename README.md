# IELTS Focus v4.0

完整的 S3 Focus 训练网站。电脑和手机使用同一份响应式页面。

## 当前状态

完整普通源码已还原并提交到根目录 `index.html`，不是 Lite 版。页面不需要构建或后端。

**首次发布仍需仓库管理员开通 GitHub Pages。** 当前连接无法修改这项管理设置。进入 Settings → Pages，设置：

- Source：Deploy from a branch
- Branch：main
- Folder：/(root)
- 点击 Save

配置正确后由 GitHub 内建 Pages 流程发布，无需再运行自定义部署工作流。

目标网址：https://yueert1997ai-sys.github.io/IELTS-focus/

## 内容清单

- 压缩训练：28 个单选题组，共 140 道单选；15 组匹配。
- 选项上膛：20 个主题，80 道单选、20 组五选二、80 道匹配小题，共 200 个得分点。
- 保留动作建立、连续迁移、完整讨论、难度选择、文字高亮、复盘与导入导出。
- 保留白底 UI、电脑与手机排版、本地训练记录及自然化系统 TTS。
- 无登录、无 Supabase、无云同步、无外部神经音频链接。
- 原创练习及合成声音未经过 IELTS 官方难度校准。

## 使用与存档

网站正式发布后，iPhone 用 Safari 打开网址，桌面用普通浏览器打开相同网址。记录只存当前浏览器；不同设备不互通。清除网站数据或使用无痕窗口可能无法保留记录。下载 HTML 在不同文件路径打开时，旧存档不保证自动继承。
